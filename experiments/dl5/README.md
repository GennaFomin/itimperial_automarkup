# Очередь экспериментов на DL5

Скрипты живут в `~/praxis/app/` на DL5 и запускаются отсоединённо (`setsid nohup`).
Этапы связаны маркерами в логах `~/praxis/logs/*.log`, каждый ждёт предыдущий:

| этап | скрипт | маркер готовности |
| --- | --- | --- |
| контроль архитектуры (2 стадии, ансамбль по инициализациям) | `run_stages.sh` | `контроль архитектуры готов` |
| ранжирование на pool_atomic с лучшим декодером | `rank85_dl5.sh` | `ранжирование готово` |
| чистый режим кейса (шаги ≥ 1.5 с) | `run_clean.sh` | `чистый режим готов` |
| A/B энкодеров признаков | `run_backbones.sh` | `A/B энкодеров готов` |
| пустые окна и выраженность пика | `run_idle.sh` | `пустые окна готовы` |

`supervise.sh` раз в пять минут перезапускает упавший этап; обучения идемпотентны —
готовый чекпоинт не переучивается. `repair_queue.sh` возвращает сервис признаков на
timesformer, стирает устаревшие маркеры и перезапускает всё в правильном порядке.

Скрипты копировать на DL5 **файлом по scp**, не heredoc через ssh: вложенные кавычки в
ssh-команде дважды искажали проверки `/health` и вешали очередь на часы.
